{%- comment -%} Analytics loaders (head). Included by base.html, base-presell.html and base-landing.html so the three layouts never drift. Bootstraps the GTM container + Meta Pixel + (Route C) GA4 + AppLovin Axon + Taboola — the Campaign Cart SDK (config.js analytics providers) sends PageView + ecommerce events, so there is intentionally no manual fbq('track','PageView') here (it would double-fire, #79). Gated on a non-empty id (`!= ""`, LiquidJS treats "" as truthy) and non-development builds. Set gtm_id / fb_pixel_id / ga4_id / axon_event_key / taboola_account_id to "" in campaigns.json to omit. See docs/campaign-page-kit-template-context.md. GA4, Axon and Taboola (apollo) are Route C, code-controlled direct integrations (no GTM container): a per-vendor bootstrap here + the shared next-forwarder-core.js loaded once + one adapter per vendor (ga4/axon/taboola.adapter.js) mapping the SDK's dl_* stream to each vendor's events. Upsells: GA4 and Taboola send a distinct `upsell_purchase` custom event (Approach C, clean count); Axon (fixed event list) sends `purchase` (Approach B — count inflates). page_view: GA4/Axon forward it from dl_user_data; Taboola's base pixel fires its own, so that adapter skips dl_user_data.
