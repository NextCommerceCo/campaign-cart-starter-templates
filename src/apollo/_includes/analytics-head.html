{%- comment -%} Analytics loaders (head). Included by base.html, base-presell.html and base-landing.html so the three layouts never drift. Bootstraps the GTM container + Meta Pixel + (Route C) GA4 + AppLovin Axon + Taboola + Triple Whale — the Campaign Cart SDK (config.js analytics providers) sends PageView + ecommerce events, so there is intentionally no manual fbq('track','PageView') here (it would double-fire, #79). Gated on a non-empty id (`!= ""`, LiquidJS treats "" as truthy) and non-development builds. Set gtm_id / fb_pixel_id / ga4_id / axon_event_key / taboola_account_id / triplewhale_name to "" in campaigns.json to omit. See docs/campaign-page-kit-template-context.md. GA4, Axon, Taboola and Triple Whale (apollo) are Route C, code-controlled direct integrations (no GTM container): a per-vendor bootstrap here + the shared next-forwarder-core.js loaded once + one adapter per vendor (ga4/axon/taboola/triplewhale.adapter.js) mapping the SDK's dl_* stream to each vendor. Upsells: GA4/Taboola/Triple Whale send a distinct upsell event (Approach C, clean count); Axon (fixed event list) sends `purchase` (Approach B — count inflates). page_view: GA4/Axon forward it from dl_user_data; Taboola + Triple Whale base pixels fire their own, so those adapters skip dl_user_data. Triple Whale is a page-side function-call API and can send RAW email/phone via the core's onContact identity hook — OFF unless triplewhale_contact_enabled is set (consent-gated on accepts_marketing).
