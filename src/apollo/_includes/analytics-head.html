Bootstraps the GTM container + Meta Pixel + (Route C) GA4 — the Campaign Cart SDK (config.js analytics providers) sends PageView + ecommerce events, so there is intentionally no manual fbq('track','PageView') here (it would double-fire, #79). Gated on a non-empty id (`!= ""`, LiquidJS treats "" as truthy) and non-development builds. Set gtm_id / fb_pixel_id / ga4_id to "" in campaigns.json to omit. See docs/campaign-page-kit-template-context.md.
