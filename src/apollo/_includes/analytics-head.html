Bootstraps the GTM container + Meta Pixel + (Route C) GA4 + (Route C) AppLovin Axon — the Campaign Cart SDK (config.js analytics providers) sends PageView + ecommerce events, so there is intentionally no manual fbq('track','PageView') here (it would double-fire, #79). Gated on a non-empty id (`!= ""`, LiquidJS treats "" as truthy) and non-development builds. Set gtm_id / fb_pixel_id / ga4_id / axon_event_key to "" in campaigns.json to omit. See docs/campaign-page-kit-template-context.md. GA4 and Axon (apollo) are Route C, code-controlled direct integrations (no GTM container): a per-vendor bootstrap here + the shared next-forwarder-core.js loaded once + one adapter per vendor (ga4.adapter.js, axon.adapter.js) mapping the SDK's dl_* stream to each vendor's events. GA4 sends upsells as a distinct `upsell_purchase` custom event; Axon (fixed event list) sends them as `purchase` (Approach B — purchase count inflates).
